A faster drop-in for makefun-site 1.0.0 that builds static sites byte-identically in about half the CPU time: a single-pass Markdown renderer, cached slugs, shared per-page cards, and template rendering into one output array per render, reimplementing makefun-site's own front matter, template dialect, Markdown subset, slug rule and build report from its README. Practice set: 3/3 cases identical to the reference.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
